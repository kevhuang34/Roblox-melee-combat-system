# Roblox Melee Combat System
A Roblox combat system with server-sided hit detection, custom attack animations, and a special attack with visual and sound effects.

## Features

- Server-sided hit detection
- Custom attack animations created using Roblox animator
- Disabled PVP against other players
- Special visual and sound effects for special abilities
